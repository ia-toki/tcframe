# Output-only Problems

In an output-only problem contestants don't submit a program. They submit the **outputs** for the test cases. The runner compares each submitted output with the expected one.

```cpp
void StyleConfig() {
    OutputOnlyEvaluator();
}
```

## Submission layout

Put the submitted outputs in one folder, with one file per test case. The file name is the test case name, followed by `.out`:

```
submissions-ac/
  oo_1.out
  oo_2.out
  oo_3.out
```

The test case names are the ones generated by `make`. They're shown in `build/tc/` and in the output of `grade`.

## Grading

```sh
tcframe make
tcframe grade --solution=./submissions-ac
```

Run the commands from the package folder, as with every other command.

## Results

- Every test case with a matching submitted output is graded with the scorer (default or custom, see [Scorers](./scorers)).
- A missing output counts as `WA` for that test case, and the subtask points are calculated as usual.

Example output for a folder with one output missing:

```
[ VERDICT ]
  Wrong Answer [33.33]
```
